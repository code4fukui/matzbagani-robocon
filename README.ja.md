# matzbagani-robocon

ロボット競技会の動画解析用に設計された、スムーズな逆再生機能を備えたシンプルなHTML/JS動画プレイヤーです。

このプレイヤーは、オリジナル動画と事前にレンダリングされた逆再生版の2つの動画ファイルを使用することで、シームレスな順再生と逆再生を実現しています。2つの再生時間を同期させることで、単一の逆再生可能な動画であるかのように見せています。

## デモ

[Okaki 逆再生対応動画プレイヤー - 第3回 Matz葉がにロボコン](https://code4fukui.github.io/matzbagani-robocon/)

## 機能

-   **スムーズな逆再生:** 順再生と逆再生を瞬時に切り替えます。
-   **同期されたスクラブ操作:** タイムラインスライダーをドラッグして、任意の方向のフレームをプレビューできます。
-   **シンプルなアーキテクチャ:** 静的ファイルのみで動作し、サーバーサイドの処理は不要です。
-   **スタンドアロン:** CSSとJavaScriptを内包した単一の `index.html` ファイルで動作します。

## セットアップと使用方法

### 1. 動画の事前処理

このプレイヤーを使用するには、動画ファイルの逆再生版が必要です。付属のシェルスクリプトのいずれかを使用して生成してください。

-   **標準的な逆再生動画を作成する場合:**
    ```sh
    ./movreverse.sh my_video.mp4
    ```
    これにより `my_video.mp4.rev.mp4` が作成されます。

-   **動画の高さを540pにリサイズして作成する場合:**
    ```sh
    ./movreversemp4.sh my_video.mp4
    ```
    これにより `my_video.mp4.rev.mp4` が作成されます。

**注意:** どちらのスクリプトも `ffmpeg` がインストールされている必要があります。

### 2. `index.html` の更新

`index.html` 内の `<video>` タグを編集し、自身のファイルを参照するように変更します。

```html
<!-- 変更前 -->
<video id=video src="./matz.mp4"></video>
<video id=video_rev src="./matz.rev.mp4"></video>

<!-- 変更後（例） -->
<video id=video src="./my_video.mp4"></video>
<video id=video_rev src="./my_video.mp4.rev.mp4"></video>
```

### 3. ブラウザで開く

変更した `index.html` ファイルをウェブブラウザで開き、プレイヤーを使用します。

## プレイヤーの操作

-   **▶️ PLAY**: 動画を順再生します。
-   **⏹️ STOP**: 再生を一時停止します。
-   **◀️ REVERSE**: 動画を逆再生します。
-   **タイムラインスライダー**: ドラッグして動画をスクラブ操作します。
